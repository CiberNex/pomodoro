# Pomodoro

Web simple de cronómetro Pomodoro para estudiar.

## Uso

1. Abre `index.html` en tu navegador.
2. Pulsa **Iniciar** para arrancar el cronómetro.
3. El flujo cambia automáticamente entre:
   - 25 min de enfoque
   - 5 min de descanso corto
   - 15 min de descanso largo cada 4 ciclos
4. Usa **Reiniciar** para volver al estado inicial.
